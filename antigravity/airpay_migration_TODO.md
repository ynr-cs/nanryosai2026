# AirPay移行 残タスク一覧

本ドキュメントは、決済手段を「au PAY」から「AirPay」に移行したことに伴う、未完了のタスクと修正対象ファイルのリストです。
次回以降のセッションで、このリストを基に実装と文脈の修正を行ってください。

## 1. 未実装の機能（チュートリアル / UX向上）

モバイルオーダーを初めて利用するユーザーに対し、決済のタイミングと手段を案内するオンボーディングUIの実装。

- [ ] **初回チュートリアルUIの追加**
  - **対象ファイル**: `pos/mobile-order.html` (および必要に応じて `pos/sok-to.html`)
  - **仕様**:
    - 初回アクセス時のみ全画面のオーバーレイ（CSS Scroll Snapを用いた横スワイプのカルーセル）を表示。
    - 状態は `localStorage`（例: `hasSeenTutorial=true`）で管理。
  - **スライド構成案**:
    1. 「並ばずに注文！📱」- 好きな店舗を選んでカートに入れよう。
    2. 「完成したらスマホにお知らせ🔔」- 出来上がるまで他の展示を楽しもう。
    3. 「お支払いは受取時に💳」- 呼ばれたら提供口へ。AirPay（クレカ・電子マネー・QR決済等）でお支払い！
- [ ] **フェイルセーフのテキスト追加**
  - **対象ファイル**: `pos/mobile-order.html`
  - **仕様**: 「注文を確定する」ボタン付近に「※お支払いは商品受取時に店頭で（AirPay対応）」と追記。
  - **対象ファイル**: `pos/status.html`
  - **仕様**: `ready_for_pickup` ステータス時の画面に「店頭の提供口までお越しいただき、AirPayにてお支払いをお願いいたします」と追記。
