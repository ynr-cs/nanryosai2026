# 開催概要 (Event Overview) コンテキスト

## 概要

`main/about.html` は、南陵祭2026の開催概要および来場時の注意事項を表示するページです。
もともとポータルサイトの共通メニューやフッターに「概要」へのリンクが存在していましたが、実ファイルが欠落していたため、2026年6月29日に新規作成されました。

## 実装仕様

### 構成

- **キービジュアル表示**: ページ最上部に、昨年度（2025年）の構成を参考にして、ポスター画像（キービジュアル）とテーマ・スローガンを表示するカードを追加。
- **内容の統一**: `index.html` の下部にある「開催概要」および「注意事項」セクションのHTML構造とクラスを完全に流用（丸パクリ）し、情報の不一致を防止。
- **デザイン**:
  - `style.css` で定義された共通レイアウトスタイル（`.overview-card`, `.overview-grid` など）に依存。縦長画像の肥大化を防ぐため、カード側に `padding: 24px` および中央配置を設定し、画像側は `max-width: 280px` に制限。
  - タイトル部分にはグラデーションおよびフェードインアニメーションを適用。
  - ライト・ダークモード対応：システム設定や手動設定（`data-theme`）による自動対応。

### 主要な掲載内容

1.  **キービジュアル**:
    - ポスター画像：ローカルアセット `"images/poster.jpg"` を指定し、未配置時のフォールバック先として既存のダミー画像 `"images/noimage.png"` を設定（将来のポスター確定時にファイルを置くだけで画像差し替えが可能）。
    - テーマ：「南陵祭2026」、スローガン：「南陵祭楽しすぎて滅」を表示。
2.  **開催日時・場所**:
    - 日程：2026年9月11日（金）・12日（土）※1日目（11日）は非公開につき一般来校ご遠慮。2日目（12日）一般公開：10:00 - 15:00、後夜祭：16:00 - 17:00。
    - 場所：横浜南陵高等学校（Google Mapへの外部リンク付き）。
3.  **注意事項**:
    - お車での来場ご遠慮、正門からの入場と受付義務、土足一足制、体育館での履物制限、写真・ビデオ撮影のご遠慮、敷地内および周辺の全面禁煙。
    - キャッシュレス決済：完全キャッシュレス導入（クレジットカード、電子マネー、QRコード決済の利用可能ブランド一覧を明記。※PayPayは3-1カステラ、3-2焼き鳥、3-4油うどん、3-5ペッパーランチ、3-6ケバブ、3-7豚タン、PTA販売では利用不可であることを重要事項として案内。決済サポートブースの案内は削除）。

## 技術的詳細

- **依存関係**:
  - `app-shell.js` を読み込んでおり、メニュー、共通ヘッダー、およびフッターが動的に注入されます。
  - アプリシェル側の `FOOTER_WHITELIST` に既に登録されているため、フッターおよびアンケートバナーが正常に描画されます。
- **グローバル状態**: `window.CURRENT_PAGE = 'about';` を指定しています。
