# Info Pages (`map.html`, `access.html`, `about.html`, `about-us.html`) 開発コンテキスト

本ドキュメントは、静的な情報提供ページの開発ガイドラインです。

## 1. 校内マップ (`map.html`)

- **役割**: 来場者が迷わないための地図機能。
- **実装**:
  - **画像ビューア**: フロアごとの校内図（画像）を表示。
  - **ピンチイン・アウト**: `Panzoom` ライブラリ等を使用し、スマホでの拡大縮小に対応。
  - **ピン機能 (Future)**: 企画一覧からマップへ遷移した際、該当場所をピンで強調表示。

## 2. アクセス (`access.html`)

- **役割**: 学校までの交通案内。
- **コンテンツ構造**:
  - **所在地**: 学校名（「神奈川県立横浜南陵高等学校」）と公式住所（`〒234-0053 横浜市港南区日野中央2-26-1`）。※`index.html` および `about.html` の会場住所表記も同一に統一。
  - **Googleマップ & マップ連携**: 埋め込みマップおよび Apple Maps (Place ID: `IDCEE73B74D8D9EB3`) / Google Maps へのスポット詳細リンク。
  - **来場上の注意事項**: 駐車場なし・バイク不可・正門のみ等の注意書き（常時表示）。
  - **最寄りのバス停からのご案内**: 洋光台北口（徒歩5分）、日野中央公園入口（徒歩10分）、日野小学校前（徒歩8分）を整理したアコーディオン。
  - **主要駅からのアクセス**: JR洋光台駅、京急上大岡駅、地下鉄港南中央駅、地下鉄上永谷駅からの詳細ルート（アコーディオン）。
- **UI/UX**:
  - `<details>`/`<summary>` によるアコーディオンUIで視認性とスクロール性を最適化。
  - **アイコン実装**: 以前は未読み込みの Font Awesome 依存によりアイコンが表示されない不具合があったが、全画面共通で読み込まれている **Bootstrap Icons**（`content: '\f282'; font-family: 'bootstrap-icons' !important;`）に完全統一。外部依存を排除し、開閉時の180度スムーズ回転アニメーションを安定動作させている。
  - デザインシステムの `--glass-bg` / `--card-bg` に準拠し、ダーク/ライトモード両方に対応。

## 3. 概要 (`about.html`)

- **役割**: 南陵祭のコンセプトや挨拶。
- **内容**:
  - 今年のテーマ解説。
  - 実行委員長挨拶。
  - パンフレット（PDF）へのリンク。

## 4. 開発者情報 (`about-us.html`)

- **役割**: コンピュータ科学部の紹介、制作の理念（Story）、および技術スタックの公開。
- **コンテンツ詳細**:
  - **Hero**: 「次、どこ行く？をスマホで。」というモットーと、プロジェクトのビジョン。
  - **Our Story**: 紙のパンフレットの不便さを解消したいという開発動機。
  - **Evolution**: 2025年度（静的/GAS）から2026年度（3D/Firebase/AI共創）への技術的進化。
  - **Tech Stack**: Firebase, Three.js, PWA, AI Supportの詳細な活用事例。
  - **Behind the Scenes**: AIとの開発体験や、部活動としてのこだわりを語るQ&A。
- **デザイン & コピーライティング**:
  - **Concept**: 「Digital Traditional」。和の情緒とサイバーパンクなデジタル感を融合。
  - **Visual**: グリッド背景、スキャンライン、グリッチノイズ、等幅フォントを活用したエンジニアリングな演出。
  - **Content**: 「ウェブサイトの歴史」タイムラインを追加し、2025年10月の始動からの軌跡を可視化。言葉選びは「再定義」「ハックする」など挑戦的に。
  - **Footer**: `app-shell.js` のサイドメニュー内フッターは "Powered By コンピュータ科学部" に統一し、本ページへの導線とする。

## 5. モバイルオーダー技術仕様 (`mobile-order-guide.html`)

- **役割**: システムの堅牢性を証明する「技術仕様書 (Whitepaper)」としての解説ページ。
- **ターゲット**: 校長、教頭、技術監査担当、保護者。
- **コンテンツ**:
  - **Architecture**: **GitHub Pages** (Frontend) + **Firebase** (Backend) のサーバーレス構成。
  - **Transaction Integrity**: **Cloud Functions** 経由でのみ注文を受け付ける仕様 (`allow create: if false`).
  - **Access Control**: **Deny by Default** のセキュリティルール。
  - **Lifecycle**: データ自動削除と、金銭リスクゼロ (No Payment Function) の保証。

## 6. UI/UX 共通方針

- **シンプルさ**: テキストと画像を読みやすく配置する「記事型」レイアウト。
- **ナビゲーション**: ページ上部に「戻るボタン」を配置し、ホームへの動線を確保。
- **ダークモード**: テキストの視認性を確保するため、白背景・黒文字（ライト）と黒背景・白文字（ダーク）のコントラスト比に配慮。
