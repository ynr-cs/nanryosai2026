# 企画詳細画面 (detail.html) 仕様と設計知識

このドキュメントでは、南陵祭2026公式サイトにおける main/detail.html（企画・展示・ステージ詳細ページ）のレイアウト仕様および画像フォールバック設計の重要な意思決定を記録します。

## 1. ヘッダー画像とレイアウトのデュアルモード設計 (v0.5.231)

detail.html は、企画ごとの画像登録有無に応じて最適な表示モードを自動的に切り替えます。

### 1.1 画像登録あり（ヒーロー画像モード）
- **対象**: images/{id}.webp または images/{id}.png が存在し、正常にロードできた団体。
- **UI仕様**:
  - 画面上部（height: 24vh; min-height: 160px;）に写真を背景カバーとして配置。
  - 下部に向けてマスクグラデーションで自然に背景色へフェードアウト。
  - .detail-content-wrapper は margin: 16vh auto 0 により、写真の下部に覆いかぶさるように重なるリッチなカードUIを展開。

### 1.2 画像未登録（クリーンレイアウトモード）
- **対象**: 写真画像が未登録の団体（大多数の教室展示や体験企画）。
- **改善の背景**:
  - 従来は画像ロード失敗時にフォールバックとして強烈な青紫グラデーション帯（#6a11cb 〜 #2575fc）を表示し、写真もないのに画面上部に16vhの大きな隙間を空けていたため、視覚的に不気味でユーザー体験を損ねていた。
- **UI仕様**:
  - 画像が存在しない場合は、.detail-header-bg を非表示（display: none;）にする。
  - .detail-content-wrapper.no-image を適用し、margin: 0 auto; padding-top: 20px; border-radius: 0; box-shadow: none; とする。
  - 画面上部からすっきりと「団体名バッジ」「企画タイトル」「場所・ジャンルチップ」「タブ」が開始するクリーンなモバイルファーストデザインを実現。
  - ライトモード・ダークモードともに背景色（ar(--bg-color)）と完璧に調和。

## 2. 画像フォーマットの優先順位
- 高圧縮・高画質な WebP 形式（images/{id}.webp）を最優先で読み込む。
- 存在しない場合は従来の PNG（images/{id}.png）をフォールバックとして試行。
- どちらもロードできない場合のみ、画像未登録モードへ即座に切り替える。
