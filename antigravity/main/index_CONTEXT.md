# Home Page (`index.html`) 開発コンテキスト

本ドキュメントは、トップページ (`index.html`) の開発ガイドラインです。

## 1. 概要

- **役割**: アプリの玄関口（ランディングページ）。
- **目的**: ユーザーに「祭りの高揚感」を与えつつ、必要な情報へ直感的にアクセスさせる。
- **デザイン**: Vibrant（鮮やか）かつ Glassmorphism（すりガラス）を取り入れたモダンな UI。

## 2. 機能・コンテンツ詳細

### 2.1 ヒーローセクション (Hero Section)

- **ビジュアル**: 没入感のあるグラデーション背景、浮遊するオーブ装飾（110px / 80px にスリム化）。
- **コンテンツ**:
  - イベントバッジ: 日付などを表示（フォント 0.78rem、パディング 4px 12px）。
  - **大見出し**: `南陵祭 2026`（グラデーション文字、`clamp(1.8rem, 8vw, 2.5rem)` で引き締まったサイズ感）。
  - スローガン: 今年のテーマ（`clamp(0.8rem, 2.5vw, 0.92rem)`）。
- **サイズ設計**: パディング `20px 16px 28px`、下部角丸 `28px`、下マージン `20px` に抑え、ファーストビューでの圧迫感を解消。

### 2.2 カウントダウン (Countdown)

- **機能**: 現在時刻に応じたフェーズ切り替えと演出 (`index.html` 内 JS ロジック)。
  1.  **通常**: 開催まで 24 時間以上。標準表示。
  2.  **直前 (<24h)**: 開催まで 24 時間未満。テキストが赤くなり、鼓動アニメーション (`heartbeat`) が適用される。
  3.  **開催中**: 2026/9/11 9:00 - 9/12 18:00 (後夜祭含む)。カウントダウンが非表示になり、「NOW HAPPENING / 開催中」の特大バナーが表示される。
  4.  **終了**: 9/12 18:00 以降。「THANK YOU / 終了しました」が表示される。
- **デザイン**:
  - Glassmorphism スタイルのカードに Days / Hours / Minutes / Seconds をグリッド表示（通常・直前）。
  - 開催中・終了時は専用のアニメーション付きバナーを表示。

### 2.3 リアルタイム情報 (Real-time Info)

- **現状**: Firestore 連携済み。アプリ風のモバイルUIとして構築。
- **内容**: 体育館、音楽室、視聴覚室の 3 会場の状況を表示。
- **レイアウト**: スマートフォンでは横スワイプできるカルーセル形式 (Scroll Snap 使用)、PC では `auto-fit` による3列グリッド配置。
- **機能**:
  - **リアルタイム反映**: 会場管理者画面での状態更新が即座に同期される。
  - **モーダル拡大表示**: カードをタップすると、その会場の詳細（現在のイベント状態、時間、次に控えているイベント）が画面全体を覆う Glassmorphism モーダルに拡大表示され、視認性が向上する。
- **将来の実装予定**:
  - **Cloud Functions + Storage**: 現在は直接Firestoreリスニングだが、負荷対策のためにJSONキャッシュ配信の仕組みを採用する可能性あり。

### 2.4 ダッシュボード (Shortcuts) - _Coming Soon_

- **企画一覧**: 参加団体の出し物一覧へ遷移。
- **ステージ**: タイムテーブルへ遷移。
- **モバイルオーダー**: 模擬店の注文ページへ遷移。

### 2.5 企画・展示 ハイライト (Projects Highlight)

- **役割**: 出展企画をカルーセル形式で自動縦スクロール表示し、来場者の興味を惹きつける。
- **表示内容**: サムネイル画像、団体名、企画名、**キャッチコピー (`catchphrase`)**、場所、タグ。
- **テキスト仕様**: `.highlight-catchphrase`（1行省略）としてキャッチコピーを表示。紹介文 (`description`) は `detail.html` のみ。
- **無限ループ制御**: `setupHighlightAutoScroll` によりシームレスな自動スクロールループを実現。

### 2.6 モバイルオーダー推奨 (Mobile Order Promo)

- **役割**: モバイルオーダー機能（`pos/mobile-order.html`）への誘導。
- **デザイン**: 鮮やかなグラデーションと Glassmorphism を用いた強調カード。
  - **重要**: コンテンツ量に応じて高さが伸縮するよう `min-height` で制御。
- **CTA**: "Start Ordering" ボタンでオーダー画面へ遷移。
- **追加リンク**: 「システムの安全性について」へのリンク (`.promo-link-sub`) を配置。

### 2.6 本日のタイムテーブル (Today's Timetable)

- **役割**: 来場者が当日行われるステージ発表のスケジュールを直感的に把握できるエリア。
- **仕様**: `stage-list.html` と同等のリッチなタイムテーブル（ガントチャートおよびトグルスイッチ付きのリストビュー）を表示する。
- **機能**:
  - **1日目/2日目の切り替え**: タブボタンにより、「DAY 1」と「DAY 2」のスケジュールを切り替え。
  - **過去の発表切り替え**: 「過去の発表も表示する」トグルスイッチで表示情報を制御。
  - **自動日付判定**: 閲覧日（現在の日付）に応じてデフォルトのタブを自動選択。
  - **自動スクロール**: 画面ロード時、現在の時刻インジケーター位置へ自動的に横スクロールする機能。
- **実装**: `main/data/data.js` から `stageData` を読み込み、`renderGanttChart` および `renderTimelineList` で動的に描画を行う。

### 2.7 データ管理 (Data Management)

- **ファイル**: `main/data/data.js`
- **内容**: 企画データ (`projectData`) やステージデータ (`stageData`) を一元管理。
- **目的**: HTML とデータを分離し、更新性を向上。

### 2.8 開催概要 (Overview)

- **役割**: 開催日時、場所、注意事項などの基本情報を提供。
- **コンテンツ**:
  - 詳細テーブル（日時、場所、注意事項リスト）。
  - **詳細ページ遷移ボタン**: 簡易開催概要の下部に、ポスタービジュアルやスローガンが含まれる詳細概要ページ（`about.html`）への遷移ボタンを配置。
  - ※以前あった画像カードおよびテーマテキストは削除済み。
- **デザイン**:
  - `style.css` に定義された Glassmorphism デザイン (`.overview-card`, `.overview-table`) を適用。
  - 遷移ボタンには `var(--primary-gradient)` による統一されたプレミアムデザインを適用。
  - ユーザーが情報をコピーできるよう、例外的に `user-select: text` を有効化。

## 3. 実装要件

- **App Shell 統合**: `app-shell.js` によりヘッダー・フッターを動的に注入。
- **レスポンシブ**: モバイルファーストだが、PC 閲覧時も間延びしないよう `max-width` などを適切に設定。
- **セクション間余白設計**: セクション間の広すぎる隙間によるスクロール肥大化を防ぐため、各セクションの外側パディング・マージンは `padding: 0 16px 24px` / `margin: 0 auto 24px〜32px` を標準として統一。
- **CSS**: `style.css` にて一元管理。変数を活用し、ダークモードにも完全対応する。
  - **メニューフッター**: ハンバーガーメニュー内の「Powered by」セクションは、インラインスタイルを排除し `.menu-footer` クラスで管理。スマホ幅での見切れを防ぐため、他メニュー項目と共通のパディングと控えめなフォントサイズを採用している。
