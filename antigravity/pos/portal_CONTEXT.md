# ポータル (`pos/portal.html`) コンテキスト

## 1. 概要

店舗管理者が自身の店舗（模擬店）を管理するためのポータル画面です。
一般ユーザーはアクセスできず、二段階認証（Googleログイン + 店舗パスワード）が必要です。

## 2. 認証 (Authentication)

- **Step 1: Googleログイン**: `firebase.auth` を使用。ドメイン制限などは現状なし（誰でもユーザー作成自体は可能）。
- **Step 2: 店舗ログイン**: `loginStore` (Cloud Function) を呼び出し。
  - 入力されたパスワードを検証。
  - 成功時、Custom Claims (`role: store_admin`, `storeId`) を付与された状態で認証トークンがリフレッシュされる。
  - `localStorage` に `nanryosai_store_id` をキャッシュし、次回以降のログインを簡略化。

## 3. 主な機能

### A. 商品管理 (Item Management)

- **CRUD**: 商品の追加・編集・削除・販売ステータス(売切/販売中)の切り替え。
- **画像アップロード**:
  - `compressImage` 関数による **クライアントサイド圧縮** を実装。
    - **フォーマット**: WebP
    - **画質 (Quality)**: 0.8
    - **最大幅 (Max Width)**: 1200px
  - Google Cloud Storage の `products/{storeId}/{timestamp}_{filename}.webp` に保存。
- **UI**:
  - **保存ボタン**: 保存処理中、ボタンが無効化され「保存中...」スピナーが表示される。

### B. 売上ダッシュボード (Sales Dashboard)

- **指標 (Metrics)**: 本日の売上総額、注文数、客単価。
- **グラフ**:
  - `chart-hourly`: 時間別売上 (棒グラフ)
  - `chart-products`: 商品別売上構成 (ドーナツグラフ)
  - **タイムライン・インスペクター (`chart-detailed-pulse`)**:
    - 1分単位の注文分布を可視化。
    - **操作**: マウスドラッグ/タッチでのスクロール（Pan）、ホイール/ピンチでのズームに対応。
    - **動的ラベル**: ズームレベルに応じて目盛り（5分〜1時間間隔）が自動調整される。
- **データソース**: Firestore `orders` コレクション (本日のデータのみ `onSnapshot` でリアルタイム監視)。

### C. ライブフィード (Live Feed)

- 最新の注文状況をリアルタイムでリスト表示。
- 自動スクロール（新しい注文が上に追加）およびステータス変更への即時反映。
- **目的**: 繁忙期の動向を「流れ」として把握するため。

### C. 注文検索 (Order Search)

- **フィルタ**: 日付、ステータス、キーワード（レシート番号など）。
- **詳細モーダル**: 注文内容の詳細表示とステータス変更が可能。

### D. ナビゲーション

- **サイドバー**: デスクトップ用。
- **ボトムナビ**: モバイル用。

## 4. 技術的制約・セキュリティ

- **セキュリティルール**: `firestore.rules` および `storage.rules` により、認証された `storeId` 以外のデータへのアクセスは厳格にブロックされる。
- **ストレージ**: 画像アップロードは `image/webp` などの画像ContentTypeのみ許可。

## 5. トレーニングモード (`pos/training/manager.html`)

- 本番のポータル画面 (`pos/portal.html`) と同一のCSSクラス（`.top-bar`, `.sidebar`, `.main-content`, `.card` 等）およびCSS変数（カラーパレット等）を利用し、完全に同じUI/UXを提供している。
- ただし、表示されるデータはすべてオンメモリのモックデータ（`mockItems`, `mockOrders`）であり、Firebaseデータベースには一切保存・送信されない。

### モックで動作する機能（本番と同一のUI挙動）

| 機能 | 挙動 |
|---|---|
| **商品追加** | 「＋ 新規商品を追加」ボタンでモーダルを開き、`mockItems` に追加 |
| **商品編集** | 各商品の「✏️ 編集」ボタンでモーダルを開き、名前・価格・説明を変更 |
| **商品削除** | 編集モーダル内の「削除」ボタンで `mockItems` から除去 |
| **売切切替** | 販売中/売切ボタンで `isAvailable` をトグル |
| **注文詳細表示** | 注文検索テーブルの行クリックで注文詳細モーダルを表示 |
| **ステータス変更** | 注文詳細モーダルのプルダウンでステータス変更し、テーブルに反映 |
| **複合検索フィルタ** | キーワード（番号）× ステータスの複合フィルタリング |

### モックデータ構造

```js
mockItems = [ { id, name, price, desc, isAvailable }, ... ]
mockOrders = [ { id, items: [{name, qty, price}], status, total }, ... ]
```

### その他

- モーダルの開閉は `modal-overlay.open` クラスのトグルで管理（`display:none` ではなくクラスで制御）
- モバイルでは注文詳細モーダルがボトムシートとして表示される
- 操作結果はトーストメッセージ (`#toast`) で通知される
- 売上ビューはスタティックなダミー数値のみ（グラフ等は省略）
