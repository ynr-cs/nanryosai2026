# Map 2D (プロトタイプ) コンテキスト

## 概要
以前開発していた 3D マップ（コスト対効果が見合わず破棄）に代わり、Leaflet.js + 国土地理院 航空写真タイルを用いた 2D マップを採用します。
`main/mapv3/prototype_map.html` にて単一ファイルでのプロトタイプ実装が行われています。

## 技術仕様
- **地図ライブラリ**: Leaflet 1.9系 (CDN利用)
- **背景タイル**: 国土地理院 シームレス空中写真 (`https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`)
- **座標系**: 実座標 (緯度経度 EPSG3857相当)。初期の中心は横浜南陵高校付近 (`[35.3923, 139.6015]`)。
- **オーバーズーム**: 航空写真の最大ズームは 18 程度ですが、`maxZoom: 22` と設定し、タイルが無いズームレベルでも引き伸ばして表示し続けることで、ピンや建物のベクター情報を詳細に見せます。

## 機能構成 (プロトタイプ段階)
1. **建物・エリア表示**
   - 施設（生徒棟、体育館、管理棟、グラウンド等）を `L.polygon` で描画し、上にラベル (`divIcon`) を配置。
   - 渡り廊下などの立体表現は、平面地図上でレイヤーを分けて描画（`overpass` レイヤー）。
2. **屋内モード (フロア切替)**
   - 左上のUIからフロア（1F〜5F）を切り替え。
   - `INDOOR_ROOMS` に定義されたダミー座標に基づき、生徒棟内に各教室のピンを配置。
3. **アクセスルート**
   - 徒歩の動線を想定し、3つのアクセスルート（洋光台北口、日野中央公園入口、日野小学校前）をポリラインで実装。
   - 左上のUIで個別の表示・非表示の切り替えが可能。
4. **団体ピン・ゲートピン**
   - 模擬店等のダミーピンと、校門の位置を示すピンを `L.marker` (カスタム `divIcon`) で配置。屋外ピンは常時表示される仕様。
5. **作図エディタ機能**
   - 航空写真上で歩行空間（面/線）を直接描画できるツールを内蔵。
   - **モード切替**: 面(Area)・線(Path)・建物(Building)から選択してポリゴン/ポリラインを作成。
   - **メタデータ付与**: 名称(name)、種別(kind)、注記(note)、線幅(width)、レイヤー(layer)を設定可能。
   - **立体交差レイヤー**: `Leaflet.Pane` を使用し、地面(`ground`: z400)と上層(`overpass`: z450)を表現。上に渡り廊下、下に通路がある状態を重なりで表現する。
   - **滑らかな曲線**: 通学路などの表現のため、Catmull-Rom スプライン補間を用いた曲線描画（オプション）に対応。
   - **JSON出力**: 描画したカスタム要素は、そのまま本番データとして使えるJSON形式でコピー可能。

## カスタム要素 (作図エディタ) のデータ構造
エディタから出力されるJSONは以下の構造を持っています。このデータを用いて本番環境で歩行可能エリアやルートを再描画します。
```json
{
  "type": "area", // "area" | "path" | "building"
  "layer": "ground", // "ground" | "overpass"
  "name": "焼き鳥広場",
  "kind": "出店広場",
  "note": "通り抜け可",
  "width": 5, // path のみ
  "isCurve": false,
  "coordinates": [[35.386, 139.585], ...] // [lat, lng] の配列
}
```

## 今後の課題（本番向け）
- 現在はダミー座標のため、本番データ投入時は精確な実座標への置き換えが必要です。
- 単体 HTML (`prototype_map.html`) として実装されているため、最終的には `app-shell` 等のプロジェクト構造への統合が必要です。
