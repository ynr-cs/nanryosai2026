# 変化を恐れない。アジャイルで創る新しい南陵祭

文化祭の準備といえば、長大な計画と終わらない会議の連続だ。数ヶ月前から綿密なスケジュールを引き、完璧なマニュアルを作り上げる。しかし、当日の想定外のトラブルの前では、分厚いマニュアルはあっけなく無力になる。それがこれまでの「常識」だった。

私たちは、この旧態依然としたやり方を根本から変えることにした。ソフトウェア開発の世界で主流となっている「アジャイル開発」の手法を、南陵祭の運営システム構築に持ち込んだのだ。

最初から完璧なシステムを目指すことはしない。まずは「動くプロトタイプ」をいち早く作り、実環境で稼働させる。「高負荷時の処理遅延は生じないか」「通信断絶からのリカバリーは正常に機能するか」「非同期処理によるデータ不整合は起きないか」。絶え間ないテストとデータ検証を繰り返し、システムを継続的にアップデートしていく。

「計画に従うことより、変化に対応することを重んじる」。
これは単なる開発手法の話ではない。南陵祭という「生きたイベント」を成功させるための、最も合理的で確実なアプローチだ。

想定外の事態は必ず起きる。しかし、私たちは恐れない。変化を前提として作られたシステムとチームは、どんなトラブルにも柔軟に対応できる。南陵祭の成功は、分厚いマニュアルの中にあるのではない。素早い軌道修正と、絶え間ない改善の果てにあるのだ。
