# モバイルオーダーについて

南陵祭2026のWebサイトをご覧いただき、ありがとうございます。

一部でお伝えしていた「モバイルオーダー機能」について、現在の状況をご報告します。

私たちコンピュータ科学部では、文化祭をもっと快適に楽しんでいただくため、スマートフォンやタブレットから注文ができる「モバイルオーダーシステム」の開発を進めてきました。行列を減らし、待ち時間を有効に使えるようにすることを目指した仕組みです。

このシステムは今年、とある模擬店での実証実験として導入を検討していましたが、準備や運用体制を関係者と話し合った結果、今年は従来どおりの方法で出店を行うことになりました。そのため、今年の南陵祭ではモバイルオーダー機能はご利用いただけません。楽しみにしてくださっていた方には申し訳ありません。

ただ、システム自体はすでに形になっており、当日の運用手順やトラブル対応の仕組みも含めて開発は完成に近づいています。今年得た知見をもとに、来年度以降、より多くの団体で安心して使える形での導入を目指して、引き続き開発を進めていきます。

今年はぜひ、各団体の模擬店や展示をそのままお楽しみください。そして来年、進化したモバイルオーダーにご期待いただければ嬉しいです。
