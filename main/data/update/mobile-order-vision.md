# 全校の飲食店舗運営を、スマホひとつで。

今年の南陵祭で、私たちは行列そのものをなくすことに挑戦する。

これまでの南陵祭では、人気店舗の前に「注文の列」と「受け取りの列」が入り混じり、通路を塞ぐ長蛇の列が当たり前の光景だった。来場者は並ぶために南陵祭に来ているわけではない。展示を見たい、ステージを楽しみたい、友達と話したい。行列は、そのすべての時間を奪っていた。

コンピュータ科学部が開発したモバイルオーダー・POSシステムは、来場者が自分のスマートフォンから注文を完結できる仕組みだ。注文したらその場を離れてよい。商品の準備が整った瞬間、スマートフォンに呼び出し通知が届く。来場者は「並ぶ」という行為から解放され、南陵祭の全体を自由に歩き回れるようになる。

在校生は学校配布のGoogleアカウントでログインして注文する。外部の来場者は店頭のセルフオーダーで注文し、表示されたQRコードを自分のスマホで読み取ることで、呼び出し通知を自分の端末に引き継ぐ。スマートフォンを持たない人には、従来通りスタッフが口頭で注文を受ける有人レジを用意する。誰ひとり取り残さない。これが設計の出発点だ。

2026年度は最大3団体程度に限定した試験導入から始める。小さく確実に始め、来年以降の展開へつなげていく。
