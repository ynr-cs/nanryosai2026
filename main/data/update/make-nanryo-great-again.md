# Make Nanryo Great Again

南陵祭は、もっと良くなれる。私たちはそう信じている。

素晴らしい行事であることは間違いない。生徒と来場者が一体になって作り上げる一日は、この学校の誇りだ。だが毎年、同じ課題が繰り返されてきた。人気店舗の前を塞ぐ長蛇の列。騒がしさの中で起きる聞き間違いと、風に飛ばされる手書き伝票。そして疲れ果てた生徒が深夜まで続ける売上集計。誰もが「まあ、こういうものだ」と受け入れてきた不便を、私たちは受け入れないことにした。

コンピュータ科学部が開発したモバイルオーダー・POSシステムは、その第一歩だ。来場者は行列から解放され、南陵祭の全体を自由に歩ける。出店団体は手書き伝票の混乱から解放され、集計作業そのものが消える。通路が空き、来場者は安全に移動できる。技術は、人を並ばせるためではなく、人を自由にするために使う。

私たちのやり方は、すべてを自動化することではない。決済の確認は必ず人の目で行う。トラブルが起きたら迷わず紙に戻す。アナログで確実な安全策をシステムの中心に据える。派手さより、確実さ。それが「お金を扱う南陵祭の根幹」に手を入れる者の責任だと考えている。

2026年度は最大3団体程度に限定した、安全第一の試験導入から始める。小さな一歩だ。だがこの一歩が、生徒の負担を減らし、来場者の笑顔を増やし、南陵祭を次の時代へ進化させる。

行列のない南陵祭。ミスのない厨房。集計に追われない夜。私たちが目指すのは、便利なシステムそのものではなく、その先にある、もっと良い南陵祭だ。

Make Nanryo Great Again.
