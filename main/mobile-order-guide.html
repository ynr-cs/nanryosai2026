南陵祭'26を並ばずに快適に楽しむための2つの注文システムと、生徒・来場者の皆様を守る安心安全の仕組み

南陵祭2026では、模擬店の混雑や長蛇の待機列を解消し、来場される皆様や生徒の皆さんが展示・ステージを最大限に楽しめるよう、独自のオーダーシステムを導入しています。

本システムは「一般来場者の皆様向け（セルフオーダーキオスク）」と「在校生の皆さん向け（モバイルオーダー）」の2つの利用窓口があり、学校祭の現場（電波の混雑や端末スリープ）を想定した高い信頼性と、個人情報を一切保持しない厳格なセキュリティ設計を備えています。

安全性の仕組みを見る

第1部：一般来場者向け（セルフオーダーキオスク）

一般来場者の皆様は、模擬店の店頭に設置されているiPad端末（セルフオーダーキオスク）と、ご自身のスマートフォンを組み合わせて、キャッシュレス感覚でスムーズにご注文いただけます。専用アプリのインストールは不要です。

ステップ 1
店頭のiPadでメニューとトッピングを選ぶ

模擬店の前に設置されているiPadの大画面で、写真を見ながら商品を選びます。トッピングの「追加」や「抜き（からし抜き、マヨネーズ抜き等）」も画面上で指定できます。 選び終えて「注文を確認する」を押すと、画面にあなた専用の「仮注文QRコード」が表示されます。

安全の仕組み：自動リセット保護

QRコードが表示されてから20秒で確認画面、さらに10秒間操作がない場合は自動的にトップ画面へリセットされます。注文途中で離脱された場合でも、後から来た他人に勝手に操作される心配はありません。

ステップ 2
ご自身のスマホでQRコードを読み取る

お持ちのスマートフォンの標準カメラ等でiPad画面のQRコードを読み取ります。 スマホのブラウザが開き、先ほどiPadで選んだ商品と合計金額がそのまま手元のスマホ画面に表示されます。

安心の仕組み：未ログイン確認設計

QRコードを読み取った直後は、ログイン前であっても注文内容（商品・数量・トッピング）をしっかり確認できます。「自分の選んだ商品と合っているか」を手元で確認した上で次のステップへ進めます。

ステップ 3
Googleアカウントでかんたんログイン

画面の「この内容でOK」をタップし、お持ちのGoogleアカウントでログインします。 学校関係者用のアカウントは不要で、一般的なGoogleアカウントでどなたでもご利用いただけます。

安全の仕組み：二重読み取り・なりすまし防止

ログインが完了した瞬間に、サーバー側の厳格なトランザクション処理によって「この注文QRコードはログインしたあなただけのもの」として即座に所有権が紐付けられます（クレーム処理）。万が一他人が同じQRコードを後から読み取っても、注文を横取りされることはありません。

ステップ 4
注文確定と受付番号の発行

利用規約を確認して「注文を確定する」を押すと、あなた専用の「受付番号（7000番台など）」が発行されます。 同時に厨房の調理モニターに注文が届き、調理がスタートします。あとは注文状況画面を見ながら完成をお待ちください。

安全の仕組み：放置QRの自動失効タイマー

店頭のiPadでQRコードが発行されてから5分以上スマホ側で確定されなかった仮注文は、サーバー（Scheduled Function）により自動的に失効・消去されます。放置された伝票が後から不正に確定されるトラブルを防止しています。

第2部：在校生向け（モバイルオーダー）

南陵高校の生徒の皆さんは、教室や部室、校内の休憩所などからスマートフォンを使って直接模擬店のメニューを事前注文できます。

在校生モバイルオーダーの特長

生徒専用アカウント（学校Googleドメイン）でログインしていれば、校内のどこからでも模擬店のメニュー一覧を閲覧・注文できます。出来上がりのタイミングに合わせて受取カウンターへ向かうだけで受け取りが完了します。

1. 片手で快適に操作できるスマホ最適化レイアウト

スマートフォンの画面サイズを無理やり縮小する旧来の方式を廃止し、最新のCSSフレックスレイアウトを採用。 iPhoneのダイナミックアイランドやノッチ、下部のホームバーに重要なボタンが重ならないよう安全余白（セーフエリア）が確保されており、移動中でも片手で誤操作なく注文できます。

2. 重複注文の自動防止（アクティブ注文検知）

「注文が完了したか心配で、もう一度注文ボタンを押してしまった」という二重購入事故を防ぐため、システムがすでに調理中・準備中の注文がないかを常に自動監視しています。 進行中の注文がある場合は自動的に「現在の注文状況画面」へと案内され、不要な重複注文をシステムが未然に防止します。

3. 注文直前のリアルタイム営業・在庫確認

メニューを選んでいる途中で店舗が売り切れたり、調理の都合で一時休止になった場合でも、注文確定ボタンを押した瞬間に店舗の最新ステータスを自動で再検証します。 注文したのに商品が受け取れないといったトラブルを水際で確実に防止します。

4. サクサク動くカートと厳格なサーバー確定処理

カートへの追加やトッピングの変更は端末のメモリ内で行われるため、校内の電波が混雑していても通信待ちによる引っかかりがなく、軽快に操作できます。 注文確定時はGoogle Cloud上の安全なサーバーが在庫チェックと連続受付番号の発番を一括で行うため、金額の改ざんや売り切れ商品の重複販売が起きません。

第3部：共通の安心・安全設計

一般来場者向け・在校生向けを問わず、南陵祭2026オーダーシステムは「安心して使えること」「文化祭当日の過酷な環境でも止まらないこと」を最優先に開発されています。

1. 個人情報ゼロの設計（Zero PII）

当システムでは、Googleログインを利用しますが、学校側のサーバーやデータベース、アクセスログには、利用者の氏名、メールアドレス、Googleプロフィール画像等の個人情報を一切保存・保持いたしません。

不可逆暗号ハッシュによる完全匿名化

ログイン時に発行されるトークンから、不可逆な暗号化ハッシュ（HMAC-SHA256）によって「ランダムな英数字の内部識別ID」のみを生成して注文と紐付けています。 万が一外部から不正アクセスを受けた場合でも、個人を特定できるデータそのものが存在しないため、個人情報流出のリスクは原理的にゼロです。

また、アカウント設定画面からいつでもアカウントの削除（退会）を行うことができ、退会時は登録されたニックネームや通知設定などの内部レコードが直ちに完全に消去されます。

2. 電波切れ・画面スリープでも安心な多層防御同期リカバリ

文化祭当日の校内は、数千人の来場者による電波の混雑や、スマホをポケットにしまって画面がスリープする状況が頻繁に起こります。注文状況画面（status.html）では、以下の多層防御同期リカバリ機構により、注文状況を見失うことがありません。

3. リアルタイム呼出モニターと5分タイマー

注文の進行状況は、画面上でリアルタイムに切り替わります：

  • 調理中：注文が厨房に届き、調理を行っている状態
  • 準備中：調理が完了し、包装や受渡口への配膳を行っている状態
  • お呼出（完成）：受取カウンターでお渡しできる状態（呼出番号が点灯）

各模擬店の受取カウンター上部には大型の呼出モニターが設置されており、お呼出状態になるとあなたの受付番号が大きく表示されます。 出来立ての一番美味しい状態でお受け取りいただくため、呼出後は画面に5分間のカウントダウンタイマーが表示されますので、お早めにカウンターへお越しください。

4. 不正アクセス・買い占めプログラムの排除

Googleの最新セキュリティ技術「Firebase App Check (reCAPTCHA Enterprise)」を採用しています。 正規のWebブラウザ以外からの自動プログラム（Bot）による買い占めや不正な通信リクエストを通信レイヤーで遮断し、データベースへの直接書き込みもセキュリティルールにより完全に禁止しています。

よくあるご質問 (FAQ)

アプリの事前ダウンロードやインストールは必要ですか？

いいえ、一切不要です。 iPhoneのSafariやAndroidのChromeなど、普段お使いの標準WebブラウザでQRコードを読み取るだけですぐにご利用いただけます。

LINEやInstagramのカメラでQRコードを読み取っても使えますか？

アプリ内ブラウザ（LINE/Instagram等）で開いた場合でも動作しますが、Googleログインの仕様上、標準ブラウザ（SafariやChrome）への切り替え案内が表示される場合があります。画面の案内に従って「外部ブラウザで開く」を選択してください。

注文後にスマホの電池が切れてしまった場合はどうすればいいですか？

注文確定時に画面に表示された「受付番号（7000番台など）」を店舗スタッフにお伝えいただければ、店頭の管理画面で確認のうえ商品をお渡しできます。番号をお手元にお控えいただくことをおすすめします。

自分のメールアドレスや本名が学校側に伝わることはありますか？

一切伝わりません。 当システムは個人情報をデータベースに一切保存しない「ゼロ・ナレッジ設計」を採用しています。学校側や開発チームが閲覧できるのは暗号化されたランダムな英数字の内部IDのみです。
