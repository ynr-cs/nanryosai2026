# 南陵祭2026 プロジェクト 全体ディレクトリ・ファイル詳細仕様

本プロジェクト (`nanryosai-2026/`) におけるすべてのファイルおよびディレクトリの構成、ならびに各ファイルの機能・記述内容を分析した事実を記録したドキュメントです。

---

## 1. ルートディレクトリ直下のファイル群

- **.firebaserc**: Firebase プロジェクトのエイリアス設定。対象プロジェクト ID (`nanryosai-2026-a4091`) が指定されています。
- **.gitignore**: Git管理対象外とするファイル/フォルダの定義（`node_modules`、`.local`、`config.local.js` など）。
- **404.html**: 存在しないページアクセス時、または未実装機能の暫定リダイレクト時に表示されるカスタムエラー画面。`main/style.css` を適用した共通デザインシステムが使われ、トップへ戻る・前の画面に戻る・企画一覧等のショートカットリンクを提供しています。
- **CHANGELOG.md**: 変更履歴。AIモデル名や修正・追加・変更内容がパッチ番号ごとに時系列で詳細に記録されています。
- **README.md**: プロジェクト概要を定義する基本ドキュメント。
- **admin-server.js**: 開発時にローカルで `data.js` を保存・同期するための Express ローカルサーバー。ポート 3001 で起動し、`main` ディレクトリを配信します。
- **config.local.js**: ローカル開発環境でのみ使用する Firebase App Check のデバッグトークンが `window.LOCAL_ENV` として定義されているファイル。
- **cors.json**: Cloud Storage 等へのクロスオリジンアクセスを制御する CORS 設定ファイル。
- **debug_firestore_custom.js**: コマンドラインから Firestore の `stores` コレクション of 任意の店舗情報を取得・確認するための Node.js デバッグスクリプト。
- **firebase.json**: Firebase Firestore のルール・インデックスファイルパス、Functions の除外設定などを定義する構成ファイル。
- **firestore.indexes.json**: Firestore の複合インデックス設定ファイル。
- **firestore.rules**: Firestore のセキュリティルール。認証状態、店舗管理者の `storeId` カスタムクレーム、Super Admin (`ynrcs1000@gmail.com`) の権限検証を含み、不正なデータ改ざんをブロックします。注文作成 (`orders` の `create`) をクライアントから直接行うことを禁止しています。
- **generate_hash.js**: Firestore の `store_secrets` に保存する店舗パスワードのハッシュ・ソルトを `crypto` の PBKDF2 (sha512, 10000回) で生成するスクリプト。
- **group_data_requirements.md**: 参加団体が提出する情報（共通、Web広報用、モバイルオーダー商品用等）の要件と、2025年度からの主な変更点を定義したドキュメント。
- **package.json** / **package-lock.json**: Node.js 依存関係とバージョン管理用ファイル。
- **storage.rules**: Firebase Cloud Storage のセキュリティルール。商品画像のアップロード先 `products/{storeId}` に対し、当該店舗管理者以外からの書き込みの禁止、および画像ファイル以外の拒否を実装しています。
- **test-admin-server.js**: ポート 3009 で起動するテスト用のローカルサーバー。`data.js` 保存 API などを提供します。
- **無題のファイル.canvas**: Obsidian で編集可能なキャンバスファイル。

## 2. 主要ディレクトリの分析

### 📂 .agent / .firebase / .git / .obsidian / .roo / .vscode / out / map-experiments / images / video

- **`.agent/`**: AIエージェント用の日本語ワークフローやプロンプト定義などのアセットを格納。
- **`.firebase/`**: Firebase CLIツールのローカルキャッシュや設定情報を保持。
- **`.git/`**: Git バージョン管理データディレクトリ。
- **`.obsidian/`**: ドキュメント閲覧用ツール Obsidian の設定やプラグイン構成を保持。
- **`.roo/`**: Roo (AIエージェント) 用の内部コンテキスト・設定ディレクトリ。
- **`.vscode/`**: VSCode 用のタスク設定やワークスペース固有の推奨事項。
- **`images/`** / **`video/`**: 共通の画像・動画アセットフォルダ。
- **`map-experiments/`**: 校内マップのデータ構造や3D/2D表示に関するプロトタイプ実験用。
- **`out/`**: 静的ビルドやエクスポート用の出力フォルダ。

### 📂 functions/ (Firebase Cloud Functions)

- **index.js**: Cloud Functions のメイン処理コード。
  - `getNextReceiptNumber`: 競合を防ぐトランザクションを用いた、各注文経路（POS: 100~, SOK: 2000~, MOBILE: 7000~）ごとのアトミックな受付番号発番。
  - `createOnlineOrder`: 在校生ドメインチェック付きのモバイルオーダー注文作成処理。
  - `createPOSOrder`: POSレジからの注文作成処理。
  - `loginStore`: 店舗ログインパスワードのハッシュ・ソルト検証と、ログイン成功ユーザーへの role/storeId Custom Claims 付与。
  - `syncOrderToSpreadsheet` / `bulkCreateSpreadsheets`: 注文のGoogleスプレッドシート自動同期および初期シート一括生成。
  - `abandonStaleOrders`: 提供準備完了から15分超過した注文の自動キャンセルとユーザーのBANリスト登録。
- **setupVenueAdmin.js**: 催し物・ステージ会場ステータス管理用のパスワードハッシュ・ソルトを Firestore `venue_admin_config` に登録・初期設定するスクリプト。
- **package.json**: Functions の依存パッケージ管理。

### 📂 main/ (一般来場者向けWebアプリ)

- **about-us.html**: 開発元であるコンピュータ科学部の紹介。
- **account.html**: ユーザープロファイル、お気に入り企画、モバイルオーダー履歴の確認・表示画面。未認証時は `login.html` にリダイレクトされます。
- **admin_sync.html**: Firestore 上の店舗マスタデータをローカル環境の `data.js` にダンプ・同期するための管理者用操作ツール。
- **app-shell.js**: アプリ共通のヘッダー、フッター、ボトムナビ、メニューオーバーレイを動的に挿入・管理するモジュール。アクティブタブ制御、注文状態に応じたナビゲーション通知バッジの更新、テーマ切り替え機能を含みます。
- **auth.js**: Firebase の初期化（Firestore, Auth, Storage, Messaging, App Check等）を一元化する SSOT モジュール。reCAPTCHA v3 と App Check トークンウォームアップを含む Google ログイン (`signInWithPopup`) をカプセル化しています。
- **banned.html**: 注文放置のBANにより利用が制限されたユーザー向けの島流し先。
- **detail.html**: 企画・展示の個別詳細ページ。URLパラメータ (`?id=...`) で受け取ったIDに応じ、`data.js` から詳細データを取得して動的表示します。
- **index.html**: 公式サイトのホームページ。リアルタイムの催し物情報、おすすめ企画、お知らせ等を統合表示します。
- **login.html**: 共通のログイン画面。リダイレクトバリデーション（オープンリダイレクタ脆弱性対策）、在校生ログイン（`@gl.pen-kanagawa.ed.jp`）の強調枠切り替え、ポップアップブロック時の解除案内UIなどを備えています。
- **map.html**: 各フロアの画像を切り替え表示可能な校内マップページ。
- **map3d.html**: 3Dで表現された校内案内マップ画面（マップエディタv2完成後に `map.html` への統合・移行を予定）。
- **mobile-order-guide.html**: 来場者に向けたモバイルオーダーの利用開始方法、注文の流れ、注意点を記述した解説ページ。
- **projects-list.html**: 全ての企画・展示店舗を検索、タグ・フロア・提供内容（食品/展示）で絞り込める一覧画面。
- **stage-list.html**: タイムテーブル一覧と検索画面。
- **style.css**: デザインシステム共通CSS。配色、ダークモード対応、タイポグラフィ、ボタン、入力フィールド、ヘッダー/フッター、グラスモーフィズム等のCSS変数・クラス定義。
- **terms.html**: モバイルオーダー等の利用規約およびプライバシーポリシー。
- **admin/venue.html**: 会場の進行状況を先生が共有端末等から即座に更新できる管理画面。Firebase Auth を使わない独自のセッション認証で実装されており、装飾を排した極めてシンプルなUIで構成されています。
- **data/data.js**: Webサイトの初期表示・オフライン動作で参照される静的な公式企画マスタデータ (`projectData`, `stageData`)。
- **map_editor/**: マップエディタ (v1)。キャンバス上のエリア定義、編集、JSソース出力を行うHTML+JavaScriptツール。
- **map_editor_v2/**: マップエディタ (v2)。PDF・画像データ（南陵map）を背景に、壁面線やスロープ、境界定義などのベクトルデータを記述しJSオブジェクトを出力する改良型3Dエディタ。
- **lastyear/**: 前年度（2025年）の公式サイトアセットおよびデータのアーカイブ。

### 📂 pos/ (店舗運営用システム)

- **animation.html**: 呼び出し通知や調理完了などのアニメーション演出確認用の画面（削除予定）。
- **kitchen.html**: 店舗内の調理担当者が注文を管理するキッチンディスプレイ。Firestore からのリアルタイム受信により「調理中 (cooking)」⇒「受取待ち (ready_for_pickup)」⇒「提供完了 (completed)」へのステータス切り替えを制御します。
- **mobile-order.html**: 一般ユーザー（在校生）が商品選択、カスタマイズ（トッピング）、カート確認、注文送信（Cloud Functions経由）を行うモバイルオーダー注文アプリ画面。Notch回避、下部ボタン見切れ防止の余白制御がなされています。
- **monitor.html**: 呼び出し番号モニター。調理中（呼び出し前）と提供準備完了（受取可能）のレシート番号を店舗の店頭ディスプレイとしてリアルタイムで分割表示します。
- **portal.html**: 店舗管理ダッシュボード。Firestore から売り上げ・注文数をリアルタイムで集計し、Chart.js により時間帯売上推移などのダッシュボードを表示する機能や、商品の売り切れトグル制御、商品画像のアップロード機能を持ちます。
- **pos.html**: 模擬店スタッフが店頭で注文を受けるための POS レジ画面。Google認証（在校生限定）に加えて店舗ログインパスワード（PBKDF2ハッシュ）での二重ロックを実装。トッピング追加（ADD）/抜き（NO）などのカスタマイズ機能や合計金額の自動計算、注文確定（Function経由で発番）を行います。
- **presenter.html**: プロジェクターや大型外部モニター等への投影用に特化した受取待ち状況の表示画面。
- **status.html**: 注文者が自身の注文状況（調理中・受取待ち）を確認する追跡画面。受取可能時はQRコードを表示し、店舗スタッフへの提示による引換えを行います。
- **training/**: 模擬店スタッフが事前に操作方法を練習するためのオフライン・ローカルテスト環境。
  - `index.html`: トレーニング環境のポータルトップ。各画面へのリンクを提供。
  - `kitchen.html`: ダミーデータを使用したオフライン用キッチンモニター画面。
  - `manager.html`: ダミー売上データや模擬的な売り切れ操作を確認するトレーニング用ダッシュボード。
  - `pos.html`: ダミー注文と発番をローカルストレージ内でシミュレートする練習用POSレジ画面。
  - `presenter.html`: トレーニング用のテスト呼出番号プロジェクター画面。

## 3. 設計図/ ディレクトリ (システム仕様書)

- **POS_SYSTEM_ANALYSIS.md**: 既存の POS システムのコード・フロー・セキュリティを詳細に分析した仕様確認書。
- **diagram.puml**: システム構成、状態遷移、シーケンス図などを記述した PlantUML テキスト図面。印刷時の見切れを防ぐ `scale 800 width` などの調整ルールが適用されています。
- **南陵祭2026 POS・モバイルオーダーシステム 設計憲法.md**: システム全体の絶対遵守すべきアーキテクチャ・セキュリティ原則やUI決定事項（SSOT設計など）をまとめたマスター文書。
- **南陵祭2026 POS・モバイルオーダーシステム 設計計画書.md**: 実装手順、各フェーズの開発ターゲット、要件定義、および画面レイアウトを詳細に記した計画書。
- **南陵祭2026 モバイルオーダー・POSシステム 導入提案書.md**: システムの導入意義、費用対効果、当日のオペレーションプラン等を学校関係者向けに説明した提案用マークダウンファイル。
- **diagram/**: 各種システムモデル図のSVG/画像ファイル出力先。
- **sandbox/**: 一時的なドラフト仕様や確定仕様、実験用定義ファイルの置き場。
- **scrap/**: 開発時の議論ログ、問題点、タスクリストなどのスクラップ用ディレクトリ。
