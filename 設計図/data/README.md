# data ディレクトリ

このディレクトリは、南陵祭に関する様々なデータや資料を一元管理するための場所です。

## 目的

主に以下の情報を保存・管理します。
- 先生から提示された資料や意見、フィードバック
- 昨年度のデータや参考資料
- その他、プロジェクトの背景や前提となる情報などの参考データ

## ルール

- **データ構造は自由**: 厳密なディレクトリ構成やファイル命名規則は定めません。自由に保存して構いません。
- **ファイル形式**: 基本的に **Markdown (`.md`) 形式** のみを使用してください。

不要な制約をなくし、思いついた時にすぐに情報を残せる・後から見つけられる場所にすることを目的としています。
