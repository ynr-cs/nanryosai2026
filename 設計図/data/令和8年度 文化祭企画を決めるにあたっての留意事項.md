# 令和8年度 文化祭企画を決めるにあたっての留意事項

2026.6.3
活動支援G

## 1 全体概要

1) 1日目は学内公開、2日目は一般公開とする。 2日目終了後の後夜祭は体育館で行う。
2) 各クラスの生徒全員は必ず、いずれかの企画に参加する。
3) 各団体(有志団体含む)は、団体責任者(生徒)を選出し、顧問(教員)をつけること。 ただし、調理団体は調理室とテントに必ず1名ずつ顧問が必要なため、2名つける。
4) 調理団体は学校全体で、7団体までとする(ホームメイキング部は除く)。 調理団体は、全て外のテントでの販売とする。 まな板、包丁及び学校で保管しているボールや鍋等の調理器具以外は団体で用意をする。 調理団体企画は保健所に提出し、許可が下りなければ実施することができない。
5) 展示団体の「お化け屋敷・迷路」は、ごみ減量のため学校全体で3団体までとする。
6) 同じジャンルの企画の上限は最大3クラスとする。 ただし、同一学年で同じジャンルの企画は最大2クラスとする。 原則、クラス、部活動、有志団体の順で優先し、クラスは上級学年を優先する。
7) 大きな音の出る団体の発表場所については実行委員会が調整する。
8) 教室内のコンセントは使用不可。
9) 教室でBGMを流す際は、周りの企画団体に留意すること。
→大音量で流すなど、周りの企画に迷惑がかかる場合は禁止とする。
10) 1日目は異装を認める。 2日目は学校指定の制服・ジャージ又はクラスTシャツに限る。 またビブスの下は学校指定の制服・ジャージとする。 クラス企画として異装をする場合は、販売・展示場所のみで異装を認める。
※ただし、事前に企画書に記入すること。

## 2 部門概要

文化祭に参加するすべての団体は、以下の4つの部門に区分される。

|                         | ① 展示団体 | ② ステージ団体 | ③ 販売団体                          | ④ 調理団体       |
| ----------------------- | ---------- | -------------- | ----------------------------------- | ---------------- |
| **団体数 (クラス)**     |            | 原則7団体      | 特に規定なし                        | 原則7団体        |
| **装飾費 (クラス)**     |            | ¥50,000        | ¥20,000                             | ¥10,000          |
| **装飾費 (クラス以外)** |            |                | ¥10,000 ※有志団体には支給されません |                  |
| **貸付金 (クラス)**     |            |                | ¥10,000~¥100,000                    | ¥10,000~¥100,000 |


- **○装飾費** → 企画の装飾などを行う際に必要なものを購入するためのお金です。 余った分は返金です。
- **○貸付金** → 販売・調理団体の材料などを購入するお金です。 借りた分は、必ず返金してください。 貸付金で発生した利益は、生徒の活動に還元できるものの購入に使わせてもらいます。

### ★部門の詳細

**① 展示団体**･･各団体で制作したものを発表する。

- 例えば・・・アトラクション (ピタゴラスイッチ、宝探し、人探し、コーヒーカップ等)
- 制作発表(写真,絵画,文芸誌、パネル製作、動画等)
- 手作り体験
  1) 入場料を取ることはできない。
  2) 安全性を十分に考慮する。(教室での火気の使用は不可。室内を暗くしない。)
  ⇒お化け屋敷は、来場者に抱きつく・触る等の行為が無いようにする。
  3) 無料で配布するものについては、必ず企画書に明記する。
  ⇒配布できるものは、個別包装・常温保存が可能なもの・未開封の品物のみとする。 など・・・
  ※お化け屋敷、迷路に関してはゴミが多くなりすぎないように。 顧問の先生の指導のもと、計画的に設営する。

**② ステージ団体**･･･演奏、演劇などの演技を行う。

- 例えば・・・楽器演奏、ダンス発表、劇など
  1) 発表時間は後日全体で調整を行います。
  2) 団体責任者・会計責任者に加え、音響責任者・照明責任者を決めること。 音響責任者・照明責任者は事前に打ち合わせを行います。 音響・照明装置は、各団体で操作すること。 異常が生じた場合には、必ず担当の職員を呼ぶこと。 物品破損した場合も直ちに報告すること。
  3) 準備、リハーサル、発表、後片付けなどについて実行委員会の指示に従うこと。 全体の準備や後片付けなどに参加しない場合は、文化祭での活動を認めない。
  4) 準備、リハーサルを含め、ステージ使用後は清掃を行うこと。
  5) 火気厳禁。
  6) 飲食物の持ち込みは禁止。
  7) ステージの設営にあたり、ガムテープの使用は禁止する。
  8) 土足での入場は禁止(特に、後夜祭では注意すること)。
  9) 全てのステージにおいて、企画書に記載の無いメンバーの出演は認めない。
  10) 危険な行為に及んだ場合は発表を中止する。
  ※ 前日のリハーサルで必ず機器の動作確認をする。 文化祭前日は終日リハーサルとする。
  ※ 体育館放送機器 (CD再生やマイク)を使用する場合は ○月○日までに実行委員会に申し出る。

**③ 販売団体**･･手作りのもの、仕入れたもの(調理不可)を販売する。

- 例えば・・・アイスクリーム、飲料水、ハンドメイドアクセサリーなど
  1) 飲食物については、個別包装・未開封の品物のみとする。
  2) 教室での火気の使用は不可。
  3) 企画の内容に伴い、販売の値段や個数の変更することはできません。(例: じゃんけんに勝ったら2個、負けたら1個、ゲームに勝ったら50円引きなど。)
  ⇒縁日等の企画で参加費は取らず、景品を出す場合は「展示団体」の扱いになります。

**④ 調理部門**･･各団体で調理したもの(加熱処理したもの)の販売を行う。
1) 調理部門は、全て調理室で下準備をしてテントで調理、販売を行う。
① 調理の下準備 (洗う、切る等)は調理室で行い、テントでは最終的な加熱のみをテントで行う。
② テントでの加熱調理には業者から借用したガスボンベとコンロ等を使用すること。
2) 調理団体は、調理室とテントの都合により7団体までとする。 区分の内訳は、実行委員会で調整する。
3) 調理団体の企画は、保健所に提出し許可が下りなければ実施することはできない。
※保健所への企画提出は第二次企画書を元に申請します。
※申請後は内容の変更はできません。
4) 団体責任者・会計責任者に加え、衛生責任者を決めること。 衛生責任者は事前に打ち合わせを行います。

**<調理工程について>**
1) 前日調理は不可。
2) 直前に加熱処理したもの以外は販売できない。 中心部まで十分に火を通した状態で提供すること。
3) 油で揚げることは不可。
4) 提供時には、すぐに飲食するよう声をかけること。
5) 材料は十分に水洗いを行うこと。
6) 調理工程で生水(煮沸など加熱処理していない水)を使用するものは販売できない。
7) 既製品も含め生クリームは使用不可。
8) 自宅で作ったものは販売できない。
9) 作り置きはしない。
10) 食材は前日準備の際に仕入れること。 それ以前での仕入れは不可。

**調理団体で扱えない品目例(理由)**

- かき氷 (加熱工程が無い)
- タピオカ(調理後生水で冷やすため。 但し、パックのまま冷やして販売する場合は可能。)
- チョコバナナ、りんご飴(生の果実を扱う、加熱工程が無い)
- サンドウィッチ (生ものが含まれる。 但し、すべて加熱してあれば可能。)
- 自家製のごはんもの (食中毒の可能性が高い。)

**●販売・調理共通事項**
1) 原則として1日目の売上を2日目の材料費、販売品の仕入れ費等に回すことはできません。
2) 収益が出すぎないように事前に「販売・調理団体仕入れ・売上計画」を作成提出する。 食販の場合、保健所に提出している販売個数と全く異なる食数にしない。 なお、収益金は全額生徒会に寄付する。 赤字団体は収益金より1000円まで補てんする。
3) 調理室・健康福祉棟の冷蔵庫を借りて食材の保管を行います。 二次企画書提出後、活動支援Gを中心に冷蔵庫の割り振りを行います。 冷蔵庫に収まらない場合は冷蔵庫をレンタルします。 レンタル費用は生徒会費より執行しますが、当日各企画の部屋で保冷しておくクーラーボックスが必要な場合は、生徒会の貸し出し物品を貸し出します。 ただし個数の制限がありますので、なるべくクラスに呼びかけをし、企画ごとで用意をできるようクラスへの呼びかけをお願いいたします。
