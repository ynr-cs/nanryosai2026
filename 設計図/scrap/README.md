# スクラップ (scrap)

このディレクトリは、南陵祭2026 POS・モバイルオーダーシステムの設計・開発において、以下のような情報を一時的に保管・共有するための場所です。

- **アイデア**: 議論中に出てきた新しい機能や改善案の断片
- **備忘録**: 忘れそうな細かい仕様や、後で確認すべき事項
- **下書き**: 正式な設計文書にする前の一時的なメモ
- **参考資料**: 外部サイトのURLや、技術的な調査結果の断片

## 運用ルール
- 形式は自由です（Markdown推奨）。
- 情報が整理され、正式な仕様として確定した場合は、`設計図` 直下の文書や `antigravity/` 配下のコンテキストファイルに統合し、このディレクトリ内の古いファイルは削除またはアーカイブしてください。
